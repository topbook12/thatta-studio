# 🎬 ঠাট্টা স্টুডিও — Thatta Studio

**বাংলা কার্টুন বানানোর সহজ প্ল্যাটফর্ম** — গোপাল ভাঁড় স্টাইলের কমেডি কার্টুন যে কেউ ঘরে বসে বানাতে পারবেন: ক্যারেক্টর তৈরি, টাইমলাইন অ্যানিমেশন, বাংলা ভয়েস + লিপ-সিঙ্ক, আর এক ক্লিকে **প্রিমিয়াম MP4 এক্সপোর্ট**। সম্পূর্ণ **PWA** — ইনস্টল করে ইন্টারনেট ছাড়াই চালানো যায়।

---

## ✨ Features

- **🎭 ক্যারেক্টর ক্রিয়েটর** — শরীর, মাথা, পোশাক, চুল, ভয়েস — হাজারো কম্বিনেশন, বাংলা লোকাল স্টাইলে
- **🎞 স্টুডিও টাইমলাইন** — প্যারালাল মাল্টি-ট্র্যাক বিট, ড্র্যাগ-এন্ড-ড্রপ রিটাইমিং, ওয়েভফর্ম পিকস
- **🚶 রিয়ালিস্টিক মুভমেন্ট** — ইজিং কার্ভ, স্পিড কন্ট্রোল, সিউডো-3D ডেপথ (দূরে গেলে ছোট হয়), ওয়াক-চেইন (টেলিপোর্ট নেই), টার্ন (3D ফ্লিপ)
- **🎥 সিনেমাটিক ক্যামেরা** — ক্যারেক্টর ফোকাস জুম, প্যান, ইমপ্যাক্ট শেক (থাপ্পড়ে ক্যামেরা কেঁপে ওঠে!)
- **🗣 বাংলা ভয়েস + AI লিপ-সিঙ্ক** — প্রতি লাইনে TTS, ভিসেম-বিশ্লেষণ করে মুখের হাঁ-ওঠানামা
- **⚡ Sprint 7 — প্রিমিয়াম MP4 এক্সপোর্ট** — WebCodecs দিয়ে প্রতিটি ফ্রেম নিখুঁতভাবে রেন্ডার (ড্রপড ফ্রেম নেই), H.264 + AAC/Opus অডিও মিক্স, 720p/1080p, 24/30fps, টাইটেল কার্ড, ফেড-ইন/আউট, প্রগ্রেস + বাতিল
- **📴 ফুল অফলাইন PWA** — সার্ভিস ওয়ার্কার ক্যাশ, ভয়েস IndexedDB-তে সেভ (অফলাইনেও সংলাপ বাজে), ডিভাইস-লোকাল প্রজেক্ট সেভ/লোড, নতুন ভার্সন রেডি টোস্ট
- **🎨 পলিশড গ্রাফিক্স** — HiDPI (Retina) ক্রিস্প রেন্ডার, 2× সুপারস্যাম্পলড ব্যাকগ্রাউন্ড, সিনেমাটিক ভিনিয়েট

## 🧰 Tech Stack

Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · shadcn/ui · Canvas 2D ইঞ্জিন (কাস্টম) · WebCodecs + mp4-muxer · IndexedDB · Prisma (SQLite, optional cloud save) · z-ai TTS API

## 🚀 লোকালে চালান

```bash
bun install        # postinstall অটো prisma generate চালায়
bun run db:push    # sqlite স্কিমা (শুধু ক্লাউড সেভের জন্য দরকার)
bun run dev        # http://localhost:3000
```

> ডাটাবেস ছাড়াও অ্যাপ পুরোপুরি চলে — ক্যারেক্টর/সিন/প্রজেক্ট ডিভাইসেই সেভ হয়।

## ☁️ GitHub → Vercel ডিপ্লয় (৫ মিনিট)

1. **GitHub রিপো বানান ও পুশ করুন**
   ```bash
   git remote add origin https://github.com/<আপনার-ইউজারনেম>/thatta-studio.git
   git push -u origin main
   ```
2. **[vercel.com/new](https://vercel.com/new)** এ যান → GitHub রিপো **Import** করুন
3. **Environment Variables** সেট করুন:
   | Name | Value | কেন |
   |---|---|---|
   | `DATABASE_URL` | `file:/tmp/thatta.db` | ক্লাউড প্রজেক্ট সেভ (Vercel-এর ফাইলসিস্টেম এফেমেরাল — ডেটা সাময়িক) |

   > ক্লাউড সেভ দরকার না হলে ভ্যারিয়েবল না-ও দিতে পারেন — API সুন্দরভাবে 503 দেবে, অ্যাপ ডিভাইস-লোকাল মোডে চলবে।
4. **Deploy** চাপুন — `postinstall` নিজেই `prisma generate` চালায়, `Project` টেবিল প্রথম রিকোয়েস্টে অটো-তৈরি হয়।
5. ডিপ্লয় শেষে PWA ইনস্টল করে (অ্যাড্রেস বারের ➕) ফোনে অ্যাপের মতো ব্যবহার করুন!

### ভয়েস (TTS) সম্পর্কে
বাংলা ভয়েস জেনারেশন `/api/tts` এর মাধ্যমে হয়, যা z-ai SDK ব্যবহার করে। নিজের TTS সার্ভার ব্যবহার করতে চাইলে `src/app/api/tts/route.ts` এ এন্ডপয়েন্ট বদলান। একবার জেনারেট হওয়া ভয়েস IndexedDB-তে থেকে যায় — পরে অফলাইনেও প্লে/এক্সপোর্ট হয়।

## 📁 Project Structure

```
src/
├─ app/                    # Next.js App Router
│  ├─ api/tts/             # বাংলা TTS + ভিসেম এনালাইসিস
│  ├─ api/projects/        # ক্লাউড সেভ (graceful 503 without DB)
│  └─ page.tsx             # স্টুডিও / ক্রিয়েটর / কোর্স ট্যাব
├─ components/tabs/        # studio-tab, creator-tab, courses-tab
├─ components/studio/      # টাইমলাইন এডিটর
└─ lib/
   ├─ cartoon/             # 🎨 অ্যানিমেশন ইঞ্জিন
   │  ├─ engine.ts         # স্টেজ: ক্যামেরা, ডেপথ, লিপ-সিঙ্ক, এক্সপোর্ট ফ্রেম
   │  ├─ exporter.ts       # ⚡ WebCodecs MP4 পাইপলাইন
   │  ├─ draw.ts / pose.ts # ক্যারেক্টার রেন্ডার + রিয়ালিস্টিক পোজ
   │  └─ backgrounds.ts    # প্রসিডিউরাল বাংলা ব্যাকগ্রাউন্ড (2× শার্প)
   ├─ audio-store.ts       # ভয়েস IndexedDB (অফলাইন)
   ├─ local-projects.ts    # ডিভাইস-লোকাল প্রজেক্ট
   └─ tts-cache.ts         # ভিসেম লিপ-সিঙ্ক এনালাইসিস
public/
├─ sw.js                   # সার্ভিস ওয়ার্কার v2
└─ manifest.webmanifest    # PWA ম্যানিফেস্ট
```
